# Consent Receipt Checklist

Use this before an agent changes state.

## Principal

- [ ] Principal is identified.
- [ ] Reviewer or owner is identified.
- [ ] Revocation path is clear.

## Task

- [ ] Intended outcome is stated.
- [ ] Out-of-scope actions are stated.
- [ ] Success criteria are testable.

## Action

- [ ] Action type is classified: read, draft, click, write, upload, buy, publish, send, execute, merge, delete, or notify.
- [ ] State-changing actions are marked.
- [ ] Sensitive actions require explicit approval.

## Surface

- [ ] Browser, file, shell, MCP server, connector, API, database, or sandbox is named.
- [ ] Resource or domain is named.
- [ ] Access boundary is stated.

## Model And Delegation

- [ ] Model route is recorded.
- [ ] Subagent route is recorded when delegated.
- [ ] Fallback or retry behavior is stated.

## Consent

- [ ] Requested scope is recorded.
- [ ] Granted scope is recorded.
- [ ] Expiration is recorded.
- [ ] Missing consent blocks the action.

## Evidence

- [ ] Tool calls are recorded.
- [ ] Browser steps are recorded.
- [ ] Inputs and outputs are recorded.
- [ ] Changed resources are recorded.
- [ ] Human review notes are recorded.

## Recovery

- [ ] Stop rule is defined.
- [ ] Rollback path is defined.
- [ ] Escalation owner is defined.
- [ ] Review queue is defined.
